# 家庭记账本 iOS 原型功能规格

## 概述

此文档记录 `ios-ui-prototype.html` 中各页面和模块对应的真实业务功能。HTML 原型仅使用本地模拟数据和展示性交互；真实 App 实现时应以本文作为页面结构、数据要求和业务行为参考。

## 全局结构

- 原型模拟 iPhone 设备框、状态栏、安全区、底部 Home Indicator 和底部 Tab Bar。
- 主导航包含首页、记录、新增、设置四个入口。
- 详情页作为记录列表和快捷功能的下钻页面，不作为常驻 Tab。
- 所有金额使用人民币展示，真实实现应统一走金额格式化工具，避免浮点精度问题。
- 所有日期、时间和相对时间应由真实交易时间生成，原型中的日期仅为模拟内容。

## 首页 / Dashboard

### 页面目的

首页用于让用户快速了解当前账本的总体财务状态，并提供高频操作入口。

### 模块

- 顶部状态：展示当前账本名称、统计周期和页面大标题。
- 可支配余额卡片：展示本月剩余可支配金额、账本健康度和简短洞察。
- 核心数据区：展示本月支出、共同支出和待结清金额。
- 快捷操作区：提供记录一笔、查看分摊、预算进度、订阅提醒等入口。
- 今日摘要：展示当天关键记录或系统提醒。
- 7 日趋势：展示近期支出节奏和趋势摘要。

### 真实业务行为

- 可支配余额应由预算、收入或用户设置的月度可用额度扣减已发生支出得到。
- 健康度应根据预算消耗、支出节奏、待结清金额等规则计算。
- 核心数据应按当前账本和当前周期聚合。
- 今日摘要应合并交易记录、自动归类结果、预算提醒和结清状态。
- 趋势图应使用最近 7 天真实支出聚合数据。

### 状态

- 空账本：展示引导新建支出和创建预算。
- 无趋势数据：展示轻量空状态，不显示伪造图表。
- 预算超额：突出超额金额和建议动作。

## 记录列表页

### 页面目的

记录页用于按时间浏览账本交易，并支持快速筛选和进入详情。

### 模块

- 顶部统计：展示当前账本和记录总数。
- 新增按钮：进入新建支出页。
- 分段控制器：支持全部、餐饮、居家、固定等分类筛选。
- 分组列表：按日期分组展示交易记录。
- 记录行：包含类别图标、标题、副标题、时间、金额和状态。

### 真实业务行为

- 记录列表应按交易时间倒序排列。
- 分组标题应根据本地日期展示“今天”“昨天”或具体日期。
- 分类筛选应基于交易类别字段，不改变原始数据。
- 点击记录行进入详情页，并传入记录 ID。
- 新增按钮进入创建页，保存成功后刷新列表并定位到新记录。

### 数据字段

- `id`：记录唯一标识。
- `ledgerId`：所属账本。
- `title`：交易标题。
- `category`：交易类别。
- `amount`：交易金额。
- `paidByMemberId`：付款成员。
- `occurredAt`：交易时间。
- `splitType`：分摊方式。
- `settlementStatus`：结清状态。
- `note`：备注。

### 状态

- 空列表：展示添加第一笔支出的入口。
- 筛选无结果：展示清除筛选或切换分类提示。
- 加载失败：展示重试入口。

## 支出详情页

### 页面目的

详情页用于展示单笔交易的金额、分摊结构、元数据、标签、备注和历史事件。

### 模块

- 顶部返回和标记操作。
- 重点金额卡片：展示交易标题、金额、商户或说明、付款人和账本属性。
- 分摊结构：展示成员承担比例、应分摊金额和待结清金额。
- 详情信息：展示交易时间、支付方式等元数据。
- 标签与备注：展示分类标签和用户备注。
- 历史：展示确认、归类、修改和结清等事件。

### 真实业务行为

- 页面应通过记录 ID 读取完整交易详情。
- 分摊结构应由成员、分摊方式和付款人计算。
- 待结清金额应与结清记录或账本余额联动。
- 标记操作可用于将记录加入重点、报销、复核或收藏类状态，具体用途需在产品需求中确定。
- 历史事件应记录用户操作和系统自动处理行为。

### 状态

- 记录不存在：展示错误状态并允许返回列表。
- 记录已结清：隐藏或弱化待结清操作，展示结清时间。
- 记录有修改历史：展示修改前后关键字段。

## 新建 / 编辑支出页

### 页面目的

创建页用于快速录入一笔支出，并设置类别、日期、付款人、分摊方式、提醒和备注。

### 模块

- 顶部取消和快捷保存操作。
- 金额输入卡片。
- 基础信息表单：标题、类别、日期。
- 分摊方式表单：付款人、平均分摊、按成员、个人支出。
- 结清提醒开关。
- 备注文本区域。
- 完成和稍后再填按钮。

### 真实业务行为

- 完成按钮应校验必填字段并保存记录。
- 取消按钮应在有未保存修改时提示确认。
- 稍后再填可保存草稿，或返回上级页面，具体行为需由产品确认。
- 类别选择应打开分类选择器。
- 日期选择应打开日期时间选择器。
- 付款人选择应基于当前账本成员。
- 分摊方式切换应改变后续输入项：平均分摊无需额外比例；按成员需要填写成员金额或比例；个人支出不进入共同分摊。
- 结清提醒开启后，应在保存后生成提醒或待结清提示。

### 校验规则

- 金额必须大于 0。
- 标题不能为空，建议限制长度，超长内容在列表中截断显示。
- 类别不能为空。
- 日期不能晚于系统允许的未来范围，是否允许未来支出需由产品规则确定。
- 付款人必须是当前账本成员。
- 按成员分摊时，各成员金额合计应等于总金额。

### 状态

- 保存中：按钮进入加载状态，避免重复提交。
- 保存失败：展示错误提示，保留用户输入。
- 草稿存在：再次进入时可恢复草稿。

## 设置页

### 页面目的

设置页用于管理账本成员、数据同步、提醒、外观、安全、导出和版本信息。

### 模块

- 账本资料卡片：展示账本名称、成员和同步说明。
- 账户组：家庭成员、数据同步。
- 偏好组：预算提醒、外观。
- 安全与数据组：Face ID 解锁、导出账本。
- 关于组：原型版本和应用信息。

### 真实业务行为

- 家庭成员入口应支持查看成员、邀请成员、调整成员名称或权限。
- 数据同步应展示真实同步状态、最近同步时间和错误恢复入口。
- 预算提醒开关应控制预算相关通知。
- 外观应支持跟随系统、浅色、深色。
- Face ID 解锁应调用系统生物识别能力，并提供失败后的备用方式。
- 导出账本应支持 CSV、PDF 月报等格式，导出前允许选择时间范围和账本。

### 状态

- 离线：同步项展示离线状态和稍后重试。
- 权限不足：成员管理、导出等入口展示受限说明。
- 生物识别不可用：Face ID 开关禁用并说明原因。

## 原型交互映射

- Tab Bar 切换：真实 App 中对应主导航状态切换。
- 分段筛选：真实 App 中对应记录查询条件。
- 列表进入详情：真实 App 中应携带记录 ID。
- 表单开关和芯片：真实 App 中应更新表单状态和保存字段。
- Toast：真实 App 中可替换为系统提示、页面内反馈或错误提示。

## 本地资产

当前原型没有使用 `prototype-design/assets/` 下的本地图片、纹理或独立图标资源。若后续生成可复用视觉资产，应创建 `assets/` 子目录，并在本文记录文件名、用途和引用页面。
